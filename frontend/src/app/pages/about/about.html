О системе

Сервис помогает ИТ-отделу учебного центра регистрировать обращения по компьютерам, проекторам и сетевому оборудованию, а пользователям — видеть состояние заявок.

Полная система будет работать по цепочке Angular → HTTP/JSON → Flask → MySQL: интерфейс показывает данные, сервер проверяет запросы, а база данных хранит состояние.

В первой лабораторной работе используется только Angular-интерфейс с демонстрационными данными в памяти браузера. API и постоянное хранение будут подключены позже.
